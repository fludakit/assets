# Fluda Assets

Brand assets for the Fluda project.

## Logo

| File | Format | Description |
|------|--------|-------------|
| `fluda.svg` | SVG | Primary logo |
| `fluda-transparent.png` | PNG | Logo with transparent background |

## Icons

| File | Size | Description |
|------|------|-------------|
| `fluda-32.png` | 32x32 | Small icon |
| `fluda-48.png` | 48x48 | Medium icon |
| `fluda-64.png` | 64x64 | Large icon |
| `fluda-128.png` | 128x128 | Extra-large icon |
| `favicon.ico` | Multi | Favicon for browsers |
